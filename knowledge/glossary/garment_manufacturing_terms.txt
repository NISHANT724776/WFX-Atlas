TERM: Colour dependency
DEFINITION: How a BOM line takes its colours. Three types: Base Colour (apparel colours used directly), Table (the user maps each apparel colour to a material colour from the material colour master) and None (no colour).

TERM ID: TERM-COLOUR-DEPENDENCY-TABLE
TERM: Colour dependency – Table
DEFINITION: The user maps each apparel colour to a material colour. It tells the system "buy the fabric in this colour to achieve the apparel in that colour". The apparel colour master and the fabric (or any raw material) colour master can differ, so this map bridges them.

TERM ID: TERM-ARTICLE-CODE-AND-ARTICLE-NAME-GENERATION
TERM: Article Code and Article Name generation
DEFINITION: The article code and article name of a techpack are generated in one of two ways: Automatically or Manually. Manually, the user types the code or name. Automatically, the system builds it from the rules set up in Admin › System Coding.

TERM ID: TERM-ARTICLE-CODE-DEFINITION
TERM: Article Code Definition
DEFINITION: A definition has a Category and a Logic (Manual or Automatic). For automatic logic each rule picks a Material Type, Product Group and Sub Category (or "ALL Other"), then lists code sections in Sort order (10, 20, 30…). The code is the sections joined in that order.

TERM ID: TERM-ARTICLE-SELECTION-MODES
TERM: Article selection modes
DEFINITION: Mode A is Style + Color + Size: one row per unique combination with Number of Sets, Size, Selling Price, Value and Total Quantity. Mode B is Style-wise grouping: one group per style with Color/Size, Quantity, Selling Price, Value, BOM and Total Quantity. A TBA colour/size line is always created by default.

TERM ID: TERM-BUYER-STYLE-REFERENCE-BSR
TERM: Buyer Style Reference (BSR)
DEFINITION: Shown under the article. Non-textile: taken from the Tech Pack, otherwise blank. Textile/fabric: taken first from the Linked Customer table for the selected buyer, then from the Tech Pack, otherwise blank. Whether the value can be edited follows the BSR configuration.

TERM ID: TERM-PACKING-TYPE
TERM: Packing Type
DEFINITION: Chosen per article: Solid Color / Solid Size (a single colour and size, existing popup), Solid Color / Assorted Size (a PP column; one colour only, ratios across sizes) and Multiple Prepack (PP ratios across colours and sizes). TERM ID: TERM-KIT-ARTICLE
TERM: Kit article
DEFINITION: A delivery cannot mix kit and non-kit articles. The first article chosen fixes the type and later selections show only that type. Kit articles are shown in grid view only, with the kit name and kit ID and an indicator.

TERM ID: TERM-SHRINKAGE
TERM: Shrinkage %
DEFINITION: Allowance for size reduction after washing or finishing. It is the last step of the chain: Cons incl Shrinkage = Cons incl Wastage ÷ (1 − Shrinkage %).

TERM ID: TERM-FINAL-CONSUMPTION
TERM: Final Consumption
DEFINITION: The last figure of the consumption chain, also called the total consumption of the line: Cons × 1/(1 − Loss %), then + Wastage %, then ÷ (1 − Shrinkage %). MRP and FPO multiply quantity by it.

TERM ID: TERM-TOTAL-CONSUMPTION
TERM: Total consumption
DEFINITION: The final figure of the chain loss → wastage → shrinkage, i.e. Final Consumption. If only one of loss, wastage or shrinkage is filled, only that step runs and its result becomes the total consumption. Not the same as Total Cons Qty, the quantity the user enters for Cons per Item garments.
