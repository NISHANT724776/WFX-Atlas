PROCEDURE ID: PROC-STYLE-BOM-NEW-BOM-SETUP
TITLE: What do I set up before running production from the new BOM?
TOPIC: New BOM setup
MODULE: Style & BOM
SOURCE DOCUMENT: New BOM, Recipe Management and MRP SOP
CONTENT: Four things are defined first: the Operation Library, the Operation Time Component, the Operation Cost Template and the Operation Parameter. Together they say which production processes exist, how long they take, what they cost and how efficient they are.
STEPS:
  1. Operation Library: add the production processes, then define operations and sub-operations (and machine sub-categories if required).
  2. Operation Time Component: add time components such as production time, queue time and preparation time.
  3. Operation Cost Template: add operation costs such as production charges, overhead and dyeing charges, with their cost components.
  4. Operation Parameter: define efficiency and loss % against the production process, operation and sub-operation.

PROCEDURE ID: PROC-STYLE-BOM-RECIPE-MANAGEMENT
TITLE: How is recipe management set up?
TOPIC: Recipe management
MODULE: Style & BOM
SOURCE DOCUMENT: New BOM, Recipe Management and MRP SOP
CONTENT: Recipes describe a dyeing or wet process. You create a recipe group, a recipe category, optionally a light master, and then the recipe itself.
STEPS:
  1. Recipe Group: create it for the categories and product group sub-categories (Production > Recipe > Recipe Group).
  2. Recipe Category: create it so that recipes can be created (Production > Recipe > Recipe Category).
  3. Light Master (optional): shows which type of light is used in the process (Production > Recipe > Light Master).
  4. Recipe: create it by adding the total water consumption and the liquid consumption.
WHERE IN WFX: Production > Recipe

TOPIC: Manufacturing BOM
MODULE: Style & BOM
SOURCE DOCUMENT: New BOM, Recipe Management and MRP SOP
CONTENT: Mark the fabric as Manufacturing and attach a Manufacturing BOM to it. After the total BOM cost is approved, the cost of the processed fabric updates automatically in the Style BOM once the fabric BOM is attached to it.
STEPS:
  1. Mark the fabric article as Manufacturing.
  2. Add a new BOM under the fabric article.
  3. Define the articles that are to be processed to produce the main fabric article.
  4. Add a recipe if one is required.
  5. Approve the total BOM cost; the fabric cost then flows into the Style BOM.

PROCEDURE ID: PROC-STYLE-BOM-MRP-WITH-THE-NEW-BOM
TITLE: How do I run MRP with the new BOM and a manufacturing fabric?
TOPIC: MRP with the new BOM
MODULE: Style & BOM
SOURCE DOCUMENT: New BOM, Recipe Management and MRP SOP
CONTENT: Link the buyer order with the actual order quantity and attach the orders, run MRP, and mark the order quantity as Mark for Purchase or Mark for Production. A second level of MRP generates the recipe articles when a recipe is attached at the second level.
STEPS:
  1. Link the buyer order with the actual order quantity and attach the orders.
  2. Run MRP and mark the order quantity as Mark for Purchase or Mark for Production.
  3. Run the second level of MRP to generate the recipe articles, if a recipe is attached at the second level.
  4. Two production orders are created because the fabric has a manufacturing BOM: one against the style and one against the fabric article.
  5. A PD is also created at material requirement planning, because processes are defined in Material Linkage in both the fabric BOM and the style BOM.
  6. Define the FPO and FPPOs for both the manufacturing BOM (process order) and the production orders and proceed.
WHERE IN WFX:
NOTES: If the required quantity does not come against the recipe article, check that a conversion is defined between the Sample Weight UOM and the article UOM on the recipe.

PROCEDURE ID: PROC-STYLE-BOM-CREATE-APPAREL-TECHPACK-BOM-ROUTING
TITLE: How do I create an apparel techpack with its BOM and routing?
TOPIC: Apparel techpack, BOM and routing
MODULE: Style & BOM
SOURCE DOCUMENT: Owner's explanation (DOC-0181) and the Apparel techpack screen of Adi TShirt (NIS-59) (DOC-0182)
CONTENT: The owner creates an apparel techpack, then its BOM, then its routing. This is the normal flow, to run without hindrance.
STEPS:
  1. Create the Material Type for the Apparel category in setup (done once), then select it from the dropdown of the techpack: the information below it depends on it.
  2. The Article Code is generated automatically by the system through System Coding. Type the Article Name (manual in this set-up).
  3. Select the Buyer. The Buyer Department list is filtered to that buyer: select the department. The Division fills in by itself.
  4. Select the Product Group and the Sub-Category.
  5. The Purchase UOM is PCS.
  6. Select the Colour Card and the Size Range that were made in the masters.
  7. Choose Price Per: Article, Color, Size or Color/Size. It decides how the delivery-level grid of the Sales Order / Purchase Order from Buyer is formed.
  8. In the BOM the sections come from the cost sheet template (categories such as fabric, trims, yarn, miscellaneous). Define the Purchase UOM and the Cons UOM of each material, add the colours and sizes needed and map them according to the dependency selected.
  9. On the Routing page of the BOM define the processes (for example cutting, stitching, sewing, packing). For each process define the input item and the output item, the After Process (the first process has none) and the Process Rate.
  10. Map the raw materials to the processes: the fabric goes through cutting, then the fabric, thread and other items go to sewing, and the final garment with the polybag goes to packing.
WHERE IN WFX: Product Development › Apparel Techpack, then BOM › Materials and BOM › Routing
NOTES: Open points: which fields change with each Material Type; where cost sheet templates are defined; whether "stitching" and "sewing" are one process; the size layout of the Color/Size grid. The Process Rate formula is still under review (CALC-ROUTING-PROCESS-RATE). The screen also shows (visual observation, not confirmed behaviour): tabs Techpack, Approvals, Variant, Log, History, BOM, Operation Bulletin and Supplier Costing; buttons Supplier Material Reference, Movement UOM, Buyer Sample Approval, Import BOM, Print QR Code, Save, More and Inventory Setup; and the fields Theme, Fabric/Material, Our Contact, Bypass Material Check On Production GRN, Fabric Article, Minimum and Maximum Qty, Minimum Order Quantity, Buying Price, Season, Buyer Style Ref., Supplier and Supplier Ref., whose behaviour was not described.
