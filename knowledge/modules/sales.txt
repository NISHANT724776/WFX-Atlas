PROCEDURE ID: PROC-SALES-OC-CLOSURE-PURPOSE
TITLE: What happens to the stock when an OC is closed?
TOPIC: OC closure purpose
MODULE: Sales Order
SOURCE DOCUMENT: OC Closure Setup (new Angular page) and stock write-off configuration
CONTENT: When an OC is closed the system automatically returns and transfers out of system the material or OC stock of that closed OC. With the write-off configuration, the leftover stock is transferred to the write-off site instead.
STEPS:
WHERE IN WFX: Admin > Configurator > Configuration Rules > OC Closure Setup
NOTES: The backend must enable the new consumption marking. Once the OC Closure Setup is done you do not need the miscellaneous setting Enable Write off for Site.

PROCEDURE ID: PROC-SALES-OC-CLOSURE-CONFIGURE-HOW-TO
TITLE: How do I configure the OC Closure Setup?
TOPIC: OC closure configure how-to
MODULE: Sales Order
SOURCE DOCUMENT: OC Closure Setup (new Angular page) and stock write-off configuration
CONTENT: Open Admin > Configurator > Configuration Rules > OC Closure Setup and add a row per company: choose the inventory site, the write-off site, the category, the stock rule, the transaction type (for example FPPO) and the execution type (Factory or Outsourced), then the WIP rule, and switch the Enable toggle on. After this, when an OC is closed the leftover stock goes to the write-off site or out of system, as the rule says.
STEPS:
  1. Have the backend team enable the new consumption marking.
  2. Create the write-off site in the site master.
  3. Open Admin > Configurator > Configuration Rules > OC Closure Setup and click Add.
  4. Select the member company, inventory site, write-off site and category.
  5. Select the stock rule (OC Stock write off + Un-Reserve, or OC Stock Transfer out of system).
  6. Select the transaction type and the execution type; add more categories, transaction types or execution types with the Add buttons if needed.
  7. Select the WIP rule if needed, and for write-off the cost centre and inventory reason.
  8. Switch on the Enable toggle.
WHERE IN WFX: Admin > Configurator > Configuration Rules > OC Closure Setup
NOTES: One WIP site is mandatory in the member company and duplicate rows are not allowed.

PROCEDURE ID: PROC-SALES-OC-CLOSURE-STOCK-RULE
TITLE: What are the stock rules of the OC Closure Setup?
TOPIC: OC closure stock rule
MODULE: Sales Order
SOURCE DOCUMENT: OC Closure Setup (new Angular page) and stock write-off configuration
CONTENT: There are two stock rules. OC Stock write off + Un-Reserve: after OC closure the OC stock is first transferred to the write-off site and the stock is unreserved from that site. OC Stock Transfer out of system: after OC closure the stock of the closed OC is transferred out of system automatically.
STEPS:
WHERE IN WFX:
NOTES: If a stock rule is selected, the WIP rule is not mandatory. If OC stock write off + Un-Reserve is selected, the CM Company Rule is frozen and Write Off Site, Cost Centre and Inventory Reason (CM Transfer To Site) become mandatory.

PROCEDURE ID: PROC-SALES-OC-CLOSURE-WIP-RULE
TITLE: What are the WIP rules of the OC Closure Setup?
TOPIC: OC closure WIP rule
MODULE: Sales Order
SOURCE DOCUMENT: OC Closure Setup (new Angular page) and stock write-off configuration
CONTENT: Issued Return + Transfer Out of system: the material first returns to the site, then is transferred out of system. Issued Return: the material returns to the site. Issued Return + write off: the material first returns to the site, then is transferred to the write-off site.
STEPS:
WHERE IN WFX:
NOTES: Example: 100 MTR was issued to the floor and 90 MTR consumed; when the OC is closed 10 MTR returns to the site and is transferred out of system. A blank option is provided so a user who picked the WIP rule by mistake can clear it.

PROCEDURE ID: PROC-SALES-OC-CLOSURE-CM-COMPANY-RULE
TITLE: How does the CM Company Rule work when the OC is in one company and production in another?
TOPIC: OC closure CM company rule
MODULE: Sales Order
SOURCE DOCUMENT: OC Closure Setup (new Angular page) and stock write-off configuration
CONTENT: When the CM Company Rule toggle is on, the rule is applied to the CM company. Example: the OC is created in Company A and production happens in Company B. When the user closes the OC from Company A, the material returns from the production floor site to the Company B site, and the system creates an automatic GDI, GDN and GRN in Company B (receipt type Transfer to site). It then returns from the Company B site to the Company A site with an automatic GDI, GDN and GRN (receipt type Transfer to site). In Company A the action of the selected WIP or stock rule is taken.
STEPS:
WHERE IN WFX:
NOTES: The CM reason can only be entered when the CM toggle is on.

PROCEDURE ID: PROC-SALES-SAMPLE-BOM
TITLE: How do I create the BOM of a sample order?
TOPIC: Sample BOM
MODULE: Sales Order
SOURCE DOCUMENT: Sample Order Manual (Classic Fashion)
CONTENT: From the Sample Order View open Bill of Material and choose one of three options: create a new BOM using a layout, copy from an article (another article sampling BOM), or copy from this article’s production Bill of Material (when the sample style is copied from an existing style). The categories shown (for example Fabric and Trims) depend on the layout chosen.
STEPS:
  1. Choose the BOM option and click OK.
  2. Click Add and fill article, body type, colour, size, UOM, consumption quantity, wastage, product quantity and the other details.
  3. Click View Requirement and check the details.
  4. Click Release Requirements so that indents are generated.
  5. Find the indents in Sourcing > Indent Management > User Indent List and fulfil them.
WHERE IN WFX: Sourcing > Indent Management > User Indent List
NOTES: For indent fulfilment and receiving material see the Indent Management and Inventory manual.

PROCEDURE ID: PROC-SALES-BUYER-RETURNED-SAMPLE
TITLE: How do I receive a sample that the buyer sends back?
TOPIC: Buyer returned sample
MODULE: Sales Order
SOURCE DOCUMENT: Sample Order Manual (Classic Fashion)
CONTENT: The sample must have been dispatched as Returnable. Then do one more transaction, the Buyer Returned Sample Receipt. It then appears in the Buyer Returned Sample Receipt List.
STEPS:
  1. Dispatch the sample with Type = Returnable (a Non-Returnable sample cannot be received back).
  2. Open Sales > Sample Order > Buyer Returned Sample Receipt and create the receipt.
  3. Find it in Sales > Sample Order > Buyer Returned Sample Receipt List.
WHERE IN WFX: Sales > Sample Order > Buyer Returned Sample Receipt
