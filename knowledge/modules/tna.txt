PROCEDURE ID: PROC-TNA-TNA-SETUP-ORDER
TITLE: How do I set up TNA (Time and Action)?
TOPIC: TNA setup order
MODULE: TNA
SOURCE DOCUMENT: TNA Workflow
CONTENT: First the basic configuration is done: roles, tasks, templates, auto TNA attachment rules, reasons for task rejection and delay, and then the roles are assigned to users in the org structure.
STEPS:
  1. Create roles, department wise.
  2. Create tasks (for example order creation, cost sheet creation, purchase order), and define how each is updated, whether it goes for approval and which department it belongs to.
  3. Create a template as per the order creation date and the delivery date.
  4. Define the Auto TNA attachment rules so templates attach automatically when a sales order is created.
  5. Create the reasons for task rejection.
  6. Create the reasons for task delay.
  7. Assign the role to the user in the org structure.

PROCEDURE ID: PROC-TNA-TNA-TEMPLATE
TITLE: How do I create a TNA template?
TOPIC: TNA template
MODULE: TNA
SOURCE DOCUMENT: TNA Workflow
CONTENT: A template is named by its length, for example 50 days or 30 days, for the object Sales Order. Tasks are dragged from the task library to the task bar from the first task to the final task.
STEPS:
  1. Click New and give the template a name such as 50 days or 30 days.
  2. Select the object Sales Order.
  3. Select tasks from the task library and drag them to the task bar, from the first task to the final one.
  4. For the first and final task set the task start based on the creation date; for the other tasks choose an offset task (the parent task).
  5. Define the duration, that is the turnaround time given to complete each task.
  6. Define the role responsible for closing each task.
WHERE IN WFX:
NOTES: Only after the task is defined properly will it be visible in My Task List and the TNA dashboard.

PROCEDURE ID: PROC-TNA-CLOSING-TNA-TASKS
TITLE: Where can a TNA task be closed?
TOPIC: Closing TNA tasks
MODULE: TNA
SOURCE DOCUMENT: TNA Workflow
CONTENT: A task can be closed from the Sales Order list, from My Task List, and from the TNA dashboard. In the Sales Order list, click the TNA column to open the page with the assigned user name and target date and close the task there. My Task List is at TNA > My Task List and closing is the same.
STEPS:
WHERE IN WFX: Sales Order list (TNA column); TNA > My Task List; TNA dashboard
