CASE ID: CASE-INDENT-COMPARISON
TITLE: BBB Adhoc Indent vs Manufacture Indent (L1) vs Production Indent (L2)
KIND: comparison
TRANSACTION: Adhoc Indent; MRP; Production Indents
MODULE: Booking & sourcing; Planning
DESCRIPTION:
  Raised by: BBB Adhoc Indent = A person, manually; Manufacture Indent (L1) = MRP, automatically; Production Indent (L2) = MRP, automatically
  Raised against: BBB Adhoc Indent = Buyer Block Booking PPJ179; Manufacture Indent (L1) = Sales order GAPS.NEWOC -249.1; Production Indent (L2) = Sales order GAPS.NEWOC -249.1
  Asks to: BBB Adhoc Indent = Buy fabric; Manufacture Indent (L1) = Make the garment; Production Indent (L2) = Buy fabric
  Quantity comes from: BBB Adhoc Indent = Booked balance units; Manufacture Indent (L1) = OC colour × size qty; Production Indent (L2) = Garment qty × BOM final consumption
  Example: BBB Adhoc Indent = PPM-000735-001 · 600 KG; Manufacture Indent (L1) = PPM-000737-001 · 1,000 pcs; Production Indent (L2) = PPM-000738-001 · 1,500 KG
  Stock check: BBB Adhoc Indent = None; Manufacture Indent (L1) = None; Production Indent (L2) = Reserves BBB stock first (400 KG)
  Next document: BBB Adhoc Indent = RMPO 1229; Manufacture Indent (L1) = Production Order; Production Indent (L2) = RMPO 1230 (1,100 KG)
NOTES: The owner insists these are different flows and must never be merged.
