TRANSACTION ID: TXN-MASTERS
TRANSACTION NAME: Masters – Colour, Size, UOM
SLUG: masters
MODULE: Style & BOM
V1 MODULE LABEL: Masters
STEP: 1
NAVIGATION PATH: Setup › Colour Card / Size Range / UOM
PURPOSE: Colour card, size range, UOM master and material-wise UOM conversion that every WFX transaction reads from.
ONE LINE: The shared lists – colours, sizes and units – that every WFX document must pick from.
BUSINESS CONTEXT:
  Masters are the shared vocabulary of WFX. A colour card groups colour codes; a size range groups size codes; the UOM master lists units, and the UOM conversion table says how one unit converts to another for a specific material.
  Nothing in a transaction can use a colour, size or unit that is not in a master. Styles pick a colour card and size range, and every downstream line (BOM, booking, OC, MRP, FPO) carries the same codes, which is what lets you trace one colour from design to the factory floor.
KEYS:
  Colour: Colour Code (inside a Colour Card) (example 372 in Nis_colors)
  Size: Size Code (inside a Size Range) (example 34S in ERPSIZE)
  UOM Conversion: Article Code | From UOM | To UOM (example N-8|KG_Nis|meter)
UPSTREAM:
DOWNSTREAM:
  Apparel Style (Techpack) (apparel-style): Base colour list and base size list
  BOM – Materials & Dependency (bom-materials): UOM conversion factor (Cons UOM Price)
  Buyer Block Booking (BBB) (buyer-block-booking): Colour and size on material lines
  Purchase Order from Buyer (OC) (buyer-po): Colour × size quantity breakup
CALCULATIONS:
VERIFICATION:
FACTS:
  Colour card: Nis_colors (8)
  Size range: ERPSIZE (7)
  N-8 conversion: 1 KG_Nis = 1,000 m
CAPTURED TABLES:
  Colour Master – Nis_colors (8 rows; Color Code, Color Name, Color Card)
  Size Master – ERPSIZE (7 rows; Size Code, Size Name, Display Name)
  UOM Master & Conversion (1 rows; Article, From UOM, To UOM, Factor, Remarks)

TRANSACTION ID: TXN-BOM-MATERIALS
TRANSACTION NAME: BOM – Materials & Dependency
SLUG: bom-materials
MODULE: Style & BOM
V1 MODULE LABEL: Product Development
STEP: 3
NAVIGATION PATH: Product Development › BOM › Materials
PURPOSE: BOM material lines with consumption, wastage, loss and shrinkage maths, price conversion and colour/size dependency.
ONE LINE: How much of each material one garment needs, at what price, and which material colour goes with which garment colour.
BUSINESS CONTEXT:
  The Bill of Materials lists every raw material needed to make one garment. Each line says which material, how much of it per garment (consumption), what allowances are added (wastage, loss, shrinkage), what it costs, and – through dependency – which material colour/size is used for each garment colour/size.
  Final Consumption is the single most important number on the BOM: MRP multiplies garment quantity by it to get fabric demand, and FPO multiplies factory quantity by it to get fabric to issue.
  Price is entered per Purchase UOM (what the supplier invoices) and converted to Cons UOM (what the garment consumes) using the material UOM conversion.
KEYS:
  BOM ID: Article | BOM Name | Version (example NIS-58|#1 DP|V1)
  BOM Line ID: BOM ID | Line (example NIS-58|#1 DP|V1|1)
UPSTREAM:
  Apparel Style (Techpack) (apparel-style): Article, base colours and base sizes
  Raw Material Techpack (rm-techpack): Material article N-8, Cons UOM, buying price
  Masters – Colour, Size, UOM (masters): UOM conversion factor 1,000
DOWNSTREAM:
  BOM – Routing (bom-routing): Material linkage to a process
  BOM – Costing (bom-costing): Material cost by section
  Purchase Order from Buyer (OC) (buyer-po): BOM selected on the delivery OC
  MRP – Material Requirement Planning (mrp): Final Consumption and dependency for BOM explosion
  Sales Order Indents (MRP) (production-indents): Cons, wastage, CSV and price on the fabric indent
  FPO & FPPO (fpo): Final Consumption for fabric requirement
CALCULATIONS: CALC-BOM-CONS-QTY, CALC-BOM-LOSS-FACTOR, CALC-BOM-CONS-LOSS, CALC-BOM-CONS-WASTAGE, CALC-BOM-CONS-SHRINKAGE, CALC-BOM-FINAL-CONS, CALC-BOM-CONS-UOM-PRICE, CALC-BOM-VALUE, CALC-BOM-VALUE-CS, CALC-BOM-DEPENDENCY
VERIFICATION:

  Final Consumption: workbook 1.5 / WFX 1.5 → match
  Cons UOM Price: workbook 15000 / WFX 15000 → match
  Value: workbook 22500 / WFX 22500 → match

  Adi TShirt (NIS-59) T-1 Cons incl Wastage (2 × 2 % + 2): workbook 2.04 / WFX 2.04 → match
  Adi TShirt (NIS-59) N-8 Value (1.65 × 15,000): workbook 24750 / WFX 24750 → match

TRANSACTION ID: TXN-BOM-ROUTING
TRANSACTION NAME: BOM – Routing
SLUG: bom-routing
MODULE: Style & BOM
V1 MODULE LABEL: Product Development
STEP: 4
NAVIGATION PATH: Product Development › BOM › Routing
PURPOSE: Production processes, operations and material linkage of BOM #1 DP, which later become FPPO process orders.
ONE LINE: The ordered processes that make the garment, what each costs (Cost Of × Production Time) and which material each consumes.
BUSINESS CONTEXT:
  Routing is the ordered list of production processes that turn materials into the garment. Each process has an output item, the process it follows, and a rate. Operations break a process into machine-level steps with time.
  Material linkage tells WFX which process consumes a BOM material – fabric N-8 is required for VCutting. This is why the Level 2 production indent shows "Required For: VCutting".
KEYS:
  Routing ID: BOM ID | R<no> (example NIS-58|#1 DP|V1|R1)
  Process ID: Routing ID | Seq (example NIS-58|#1 DP|V1|R1|2)
UPSTREAM: BOM – Materials & Dependency (bom-materials): BOM ID and material lines for linkage
DOWNSTREAM:
  BOM – Costing (bom-costing): Process rates → Production Cost
  Sales Order Indents (MRP) (production-indents): "Required For" process on the fabric indent
  FPO & FPPO (fpo): Processes of the FPPO
CALCULATIONS: CALC-ROUTING-AFTER-VALID, CALC-ROUTING-PROCESS-RATE, CALC-ROUTING-LINKAGE
VERIFICATION:
FACTS:
  Processes: VCutting · Sewing · VPacking
  Rates: 300 + 10 + 15 = 325
  Linkage: Fabric → Cut, trims → Sew/Pack
CAPTURED TABLES:
  Processes (3 rows; Seq, Process, Code, Output, After, Rate, Total Time)
  Adi TShirt (NIS-59) Operations tab → Process Rate (live WFX) (3 rows; Process, Operation, Machine, Efficiency %, Cost Of, Production Time, Cost Of × Time, Process Rate (WFX))
  Adi TShirt (NIS-59) Material Linkage tab (4 rows; Line, Article, Cons UOM, Wastage %, Cons Qty, Incl Wastage & Loss, Linked Process)

TRANSACTION ID: TXN-BOM-COSTING
TRANSACTION NAME: BOM – Costing
SLUG: bom-costing
MODULE: Style & BOM
V1 MODULE LABEL: Product Development
STEP: 5
NAVIGATION PATH: Product Development › BOM › Cost
PURPOSE: Material cost, production cost, total cost, profit, profit % and markup % for BOM #1 DP.
ONE LINE: Cost per piece – material plus production – against the selling price: Profit uses the price after discount, Markup the price before it.
BUSINESS CONTEXT:
  Costing rolls up the BOM into a per-piece cost and compares it with the selling price. Material cost comes from BOM line values grouped by section; production cost comes from routing process rates.
  Profit % = (selling price after discount − total cost) ÷ selling price after discount. Markup % = (selling price before discount − total cost) ÷ total cost. Adi TShirt (NIS-59): −597.66 % and −84.07 %.
KEYS: BOM ID: Article | BOM Name | Version (example NIS-58|#1 DP|V1)
UPSTREAM:
  BOM – Materials & Dependency (bom-materials): Line Value (CS Curr) by section
  BOM – Routing (bom-routing): Process rates
DOWNSTREAM:

PURPOSE: Projection booking PPJ179 that reserves fabric by colour and size before a confirmed buyer order exists.
ONE LINE: A projection that lets you book and buy long-lead fabric before the buyer confirms the order.
BUSINESS CONTEXT:
  A Buyer Block Booking (BBB) is a projection: the buyer signals expected volume before confirming styles. It lets sourcing reserve and buy long-lead material (fabric) early, by colour and size.
  Material bought against the booking is stocked with the booking number. When the confirmed OC arrives and MRP runs, that stock is adjusted in-house automatically, so only the gap is purchased again.
KEYS:
  Block Booking No.: Code (example PPJ179)
  Booking Line No.: Booking . Line (example PPJ179.1)

DOWNSTREAM: BBB Adhoc Indent (adhoc-indent): Booked units and booking line reference

V1 MODULE LABEL: Order
STEP: 11
NAVIGATION PATH: Order › Purchase Order from Buyer (OC)
PURPOSE: Order confirmation GAPS.NEWOC -249 with delivery OC, colour × size quantity breakup and selling value.
ONE LINE: The confirmed buyer order. Its colour × size breakup is the demand MRP plans from.
BUSINESS CONTEXT:
  The buyer purchase order, captured as an Order Confirmation (OC), is the confirmed demand. A main OC holds one or more delivery OCs; each delivery OC has a BOM, a delivery date and a colour × size quantity breakup.
  Confirming the OC triggers MRP: the breakup becomes Level 1 garment demand and is exploded through the BOM.
KEYS:

  BreakUp Key: OC | Colour | Size (example GAPS.NEWOC -249.1|372|34S)
UPSTREAM:
  Apparel Style (Techpack) (apparel-style): Style, buyer, department, UOM
  BOM – Materials & Dependency (bom-materials): BOM #1 DP on the delivery OC
