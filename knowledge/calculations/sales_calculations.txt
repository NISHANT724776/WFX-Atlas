RULE ID: CALC-OC-VALUE
RULE NAME: Breakup Value
MODULE: Sales Order
SUBMODULE:
TRANSACTION: Purchase Order from Buyer (OC)
RULE CATEGORY: Calculation
BUSINESS PURPOSE: Colour × size value of the delivery OC.
TRIGGER CONDITION:
APPLICABLE CONDITIONS:
INPUT FIELDS:
  Qty
  Selling Price
  CM Price

UNIT OF MEASUREMENT:
ROUNDING RULE:
OUTPUT: Total Value
VALIDATIONS:
EXAMPLE: 300 × 33.3333 = 9,999.99 for Cosmic sky purple / Small; OC total 33,333.30 USD.

EXCEPTION CONDITIONS:

  selling_price | Selling Price | money | required

RULE ID: CALC-SO-SPLIT-PCT
RULE NAME: Split by percentage
MODULE: Sales Order
SUBMODULE:
TRANSACTION: Purchase Order from Buyer (OC)
RULE CATEGORY: Calculation
BUSINESS PURPOSE: Per the Sales Order specification. The percentage must be above 0 and not above 100; the remaining quantity stays in the source delivery.
TRIGGER CONDITION:
APPLICABLE CONDITIONS:
INPUT FIELDS:
  Existing Quantity
  Split Percentage
FORMULA / LOGIC: Split Quantity = Existing Quantity × Split Percentage ÷ 100 (per article colour/size line, rounded to the UOM precision); Remaining = Existing − Split
UNIT OF MEASUREMENT:
ROUNDING RULE:
OUTPUT: Split Quantity
VALIDATIONS:
EXAMPLE: 20 % of Red/S 100, Red/M 200, Red/L 200 moves 20, 40 and 40.
EXPECTED RESULT:
EXCEPTION CONDITIONS:
RELATED TRANSACTIONS:
RELATED RULES:
CALC INPUTS:
  existing_qty | Existing Quantity | quantity | required
  split_pct | Split Percentage | percent | required
EXPRESSION: split_qty = existing_qty * split_pct / 100
CALC OUTPUT: split_qty
V1 STATUS: verified (matches a WFX screen value)

RULE ID: CALC-SO-SPLIT-QTY
RULE NAME: Split by quantity
MODULE: Sales Order
SUBMODULE:
TRANSACTION: Purchase Order from Buyer (OC)
RULE CATEGORY: Calculation
BUSINESS PURPOSE: The entered quantity is spread proportionately over the selected colour/size lines (specification wording: "distributed proportionately"). Quantity must be above zero and not above the delivery quantity.
TRIGGER CONDITION:
APPLICABLE CONDITIONS:
INPUT FIELDS:
  Entered Quantity
  Line Qty
  Total of the selected lines
FORMULA / LOGIC: Line Split Qty = Entered Quantity × Line Qty ÷ Total of the selected lines
UNIT OF MEASUREMENT:
ROUNDING RULE:
OUTPUT: Line Split Qty
VALIDATIONS:
EXAMPLE: 100 pcs over 100 / 200 / 200 moves 20 / 40 / 40.
EXPECTED RESULT:
EXCEPTION CONDITIONS:
RELATED TRANSACTIONS:
RELATED RULES:
CALC INPUTS:
  entered_qty | Entered Quantity | quantity | required
  line_qty | Line Qty | quantity | required
  total_selected_qty | Total of the selected lines | quantity | required
EXPRESSION: line_split_qty = entered_qty * line_qty / total_selected_qty
CALC OUTPUT: line_split_qty

ROUNDING RULE:

RULE ID: CALC-SO-APPROVAL-LIMIT
RULE NAME: Approval value rule
MODULE: Sales Order
SUBMODULE:
TRANSACTION: Purchase Order from Buyer (OC)
RULE CATEGORY: Calculation
BUSINESS PURPOSE: A value equal to the limit does not go for approval.
TRIGGER CONDITION:
APPLICABLE CONDITIONS:
INPUT FIELDS:
  Approval value of the approver
  Order Value
FORMULA / LOGIC: Limit 0 → never approval; Limit -1 → always approval; Limit > 0 → approval only if Order Value > Limit
UNIT OF MEASUREMENT:
ROUNDING RULE:
OUTPUT: Approval value rule
VALIDATIONS:
EXAMPLE: Limit 1,000: order 1,000 → no approval; order 1,500 → approval.
EXPECTED RESULT:
EXCEPTION CONDITIONS:
RELATED TRANSACTIONS:
RELATED RULES:
CALC INPUTS:
  approval_limit | Approval value of the approver | number | required
  order_value | Order Value | money | required
EXPRESSION: goes_for_approval = IF(approval_limit == 0, 0, IF(approval_limit == -1, 1, IF(order_value > approval_limit, 1, 0)))
CALC OUTPUT: goes_for_approval
V1 STATUS: verified (matches a WFX screen value)

RULE ID: CALC-SO-PURCHASE-DEMAND
RULE NAME: Material indents after Purchase Demand
MODULE: Sales Order
SUBMODULE:
TRANSACTION: Purchase Order from Buyer (OC)
RULE CATEGORY: Calculation
BUSINESS PURPOSE: Purchase Demand at Level 1 is style quantity bought finished. On the next MRP run the material indents shrink by it; with the whole quantity there are none. The style indent with purchase demand goes to an RMPO.
TRIGGER CONDITION:
APPLICABLE CONDITIONS:
INPUT FIELDS:
  Level 1 Style Qty
  Purchase Demand
  BOM Final Consumption
FORMULA / LOGIC: Material Indent Qty = (Level 1 Style Qty − Purchase Demand) × BOM Final Consumption
UNIT OF MEASUREMENT:
ROUNDING RULE:
OUTPUT: Material Indent Qty
VALIDATIONS:
EXAMPLE: Order 1,000, Final Consumption 1.5: Purchase Demand 0 → 1,500; 400 → 900; 1,000 → 0.
EXPECTED RESULT:
EXCEPTION CONDITIONS:
RELATED TRANSACTIONS:
RELATED RULES:
CALC INPUTS:
  level1_style_qty | Level 1 Style Qty | quantity | required
  purchase_demand | Purchase Demand | quantity | default 0
  final_consumption | BOM Final Consumption | quantity | required
EXPRESSION: material_indent_qty = (level1_style_qty - purchase_demand) * final_consumption
CALC OUTPUT: material_indent_qty
