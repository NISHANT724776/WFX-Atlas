RULE ID: CALC-BOM-FINAL-CONS
RULE NAME: Final Consumption
MODULE: Style & BOM
SUBMODULE:
TRANSACTION: BOM – Materials & Dependency
RULE CATEGORY: Calculation
BUSINESS PURPOSE: The last figure of the chain is the total consumption MRP explodes and FPO uses. Each of loss, wastage and shrinkage is optional: when only one is filled the system applies just that step and its result becomes the total consumption.
TRIGGER CONDITION:
APPLICABLE CONDITIONS:
INPUT FIELDS:
  Cons Qty
  Loss %
  Wastage %
  Shrinkage %
FORMULA / LOGIC: Final (Total) Consumption = result of the chain: Cons Qty × 1/(1 − Loss %) → + Wastage % → ÷ (1 − Shrinkage %)
UNIT OF MEASUREMENT:
ROUNDING RULE:
OUTPUT: Final (Total) Consumption
VALIDATIONS:
EXAMPLE: Cons 2 with loss, wastage and shrinkage of 5 % each = 2.326870. Only wastage 5 % = 2.1. Only loss 5 % = 2.105263. Only shrinkage 5 % = 2.105263. Adi TShirt (NIS-59) N-8: 1.65 (WFX shows 1.65).
EXPECTED RESULT:
EXCEPTION CONDITIONS:
RELATED TRANSACTIONS:
RELATED RULES:
CALC INPUTS:
  cons_qty | Cons Qty | quantity | required
  loss_pct | Loss % | percent | default 0
  wastage_pct | Wastage % | percent | default 0
  shrinkage_pct | Shrinkage % | percent | default 0
EXPRESSION:
  loss_factor = 1 / (1 - loss_pct / 100)
  cons_incl_loss = cons_qty * loss_factor
  cons_incl_wastage = cons_incl_loss + cons_incl_loss * wastage_pct / 100
  final_consumption = cons_incl_wastage / (1 - shrinkage_pct / 100)
CALC OUTPUT: final_consumption
V1 STATUS: verified (matches a WFX screen value)

  Purchase Price
  Conversion Factor (Purchase UOM → Cons UOM)

ROUNDING RULE:
OUTPUT: Cons UOM Price
VALIDATIONS:
EXAMPLE: 15 INR/meter × 1,000 = 15,000 INR per KG_Nis (WFX shows 15,000). Trims use the default factor 1 when no UOM conversion is maintained: T-1 (PCS → meter) 10 → 10, NS1-1 8 → 8, PP-1 4 → 4.

EXCEPTION CONDITIONS:
RELATED TRANSACTIONS:
RELATED RULES:

  purchase_price | Purchase Price | money | required

RULE ID: CALC-CONSUMPTION-CHAIN
RULE NAME: Total consumption chain (loss, wastage, shrinkage)
MODULE: Style & BOM
SUBMODULE: BOM
TRANSACTION: BOM – Materials & Dependency
RULE CATEGORY: Calculation
BUSINESS PURPOSE: The final ("total") consumption of a BOM line, after loss, wastage and shrinkage. The owner calls this figure "total cons"; "Total Cons Qty" is the entered column.
TRIGGER CONDITION:
APPLICABLE CONDITIONS:
INPUT FIELDS:
  Cons Qty
  Loss %
  Wastage %
  Shrinkage %
FORMULA / LOGIC:
  Loss Factor = 1 ÷ (1 − Loss %)
  Cons incl Loss = Cons × Loss Factor
  Cons incl Wastage = Cons incl Loss + Cons incl Loss × Wastage %
  Total (Final) Consumption = Cons incl Wastage ÷ (1 − Shrinkage %)
  Each step is optional: a step whose percentage is not given is left out.
UNIT OF MEASUREMENT: Consumption UOM of the BOM line
ROUNDING RULE:
OUTPUT: Total (Final) Consumption
VALIDATIONS:
EXAMPLE: Cons 2, Loss 5 %, Wastage 5 %, Shrinkage 5 % → factor 1.0526316 → 2.1052632 → 2.2105263 → 2.3268698
EXPECTED RESULT: 2.326869806 (owner's figure)
EXCEPTION CONDITIONS: Not documented: what WFX does when Loss % or Shrinkage % is 100 (the formula divides by zero). The v1 site clamps percentages below 100; that clamp is not a documented WFX rule.
RELATED TRANSACTIONS:
RELATED RULES: CALC-BOM-LOSS-FACTOR, CALC-BOM-CONS-LOSS, CALC-BOM-CONS-WASTAGE, CALC-BOM-CONS-SHRINKAGE, CALC-BOM-FINAL-CONS
CALC INPUTS:
  cons_qty | Cons Qty | quantity | required
  loss_pct | Loss % | percent | default 0
  wastage_pct | Wastage % | percent | default 0
  shrinkage_pct | Shrinkage % | percent | default 0
EXPRESSION:
  loss_factor = 1 / (1 - loss_pct / 100)
  cons_incl_loss = cons_qty * loss_factor
  cons_incl_wastage = cons_incl_loss + cons_incl_loss * wastage_pct / 100
  total_consumption = cons_incl_wastage / (1 - shrinkage_pct / 100)
CALC OUTPUT: total_consumption
TEST CASES:
  cons_qty=2, loss_pct=5, wastage_pct=5, shrinkage_pct=5 → total_consumption=2.326869806
  cons_qty=2, wastage_pct=5 → total_consumption=2.1
  cons_qty=2, loss_pct=5 → total_consumption=2.105263158
  cons_qty=2, shrinkage_pct=5 → total_consumption=2.105263158
