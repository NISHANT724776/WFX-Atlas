# 2026-11-18T06:27:11.917Z · superseded by v3

RULE ID: RULE-SETUP-BOM-INDENT-OWNER
RULE NAME: Indents are Inactive when the BOM has no User Group and Purchase Officer
MODULE: Setup rules
SUBMODULE: BOM
TRANSACTION:
RULE CATEGORY: Business Rule
BUSINESS PURPOSE: Every indent needs an owner (User Group, Purchase Officer); the BOM supplies it, and without it the indent is held Inactive until a user takes it over.
TRIGGER CONDITION:
APPLICABLE CONDITIONS:
INPUT FIELDS:
FORMULA / LOGIC: If the BOM has no User Group and no Purchase Officer, the indents created from it are Inactive by default. The user must mark them Active manually (User Indent list or Indent list) before MRP or any other action can be done on them.
