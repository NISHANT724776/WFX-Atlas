## External blockers

| Blocker | Affects | Safe structure in place |
| --- | --- | --- |
| No AI provider key, and the organisation's approval is not yet recorded | Generative answers, semantic search, BA documents, reading images | Provider-neutral integration, admin authorisation switch with audit; every feature has a deterministic path |
| No real WFX database metadata | Physical data models | Models labelled as captured screen fields; nothing invented |
| Hosting not chosen / approved | Access from the WFX domain | One Node process with a data folder (ARCHITECTURE.md §8) |
| Owner's choice of the 205 discovered documents | Wider knowledge coverage | `knowledge/metadata/discovered_sources.json` + `npm run kb:import` |
| Owner's review of 6 rules Under Review and 1,459 candidates | Confirmed knowledge | Dashboard "Waiting for review", Library candidates, Rulebook transitions |
